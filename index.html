GUIDED PRACTICE CAPSTONE

One small project
from input to insight.

Practice one complete, local workflow using synthetic data. This is a learning exercise, not a promise of professional or portfolio readiness.

THE BRIEFCommunity-services activity summary

Use one synthetic workbook of fictional service visits. Validate its required fields, create a checked summary, show it in a simple dashboard running only on your computer, and calculate one clearly explained spatial result.

OPTIONAL LOCAL PRACTICE TOOLSPython · pandas · openpyxlStreamlit (run locally only)GeoPandas · pytest

A SMALL, BOUNDED SCOPE

Practice milestones

SYNTHETIC DATA · LOCAL ONLY
01SCOPE

Choose one question

Describe one modest question about fictional community-service activity and the fields needed to answer it.

  • Use only the provided or self-made synthetic data
  • Write down assumptions
02ONE WORKBOOK

Validate before analysis

Read one synthetic workbook, check required columns and key values, and stop with a clear issue when the schema is not usable.

  • Keep the source workbook unchanged
  • Make exclusions visible
03SUMMARY

Make one checked summary

Apply explicit cleaning rules and create a simple grouped result; compare it with a small hand calculation.

  • Define the measure and its units
  • Record what was excluded
04LOCAL DASHBOARD

Show the result locally

Present the summary in one small dashboard on your own computer, with a title, source note, and useful empty/error state.

  • Do not host or upload the app or data
  • Explain what the metric means
05ONE SPATIAL RESULT

Check one spatial result

Use fictional locations and a known CRS for one map, area join, or local distance calculation.

  • Verify CRS and measurement units
  • Distance is not travel time
06HANDOFF

Test and explain limits

Add a few tests and a README covering setup, how to run locally, synthetic-data provenance, privacy, and known limitations.

  • Keep private data and credentials out
  • Follow the instructions from a clean copy

ASPIRATIONAL CHECKLIST · NOT A GUARANTEE

Practice review rubric

Correctness

Required fields, exclusions, totals, CRS, and units are checked for this small example.

Usability

The local app labels its measure and makes an invalid or empty result understandable.

Repeatability

Tests and setup instructions help another learner reproduce the synthetic example.

Communication

The README explains assumptions, privacy boundaries, and what the result cannot tell you.

✳
This guided exercise is practice, not a portfolio-readiness or employment guarantee.

Use synthetic data only. Keep the dashboard local; this static learning course does not upload data, run Python, or provide hosting.
